# gustavoxavier.dev

Portfolio pessoal do **Gustavo Xavier** — Desenvolvedor Full Stack.

## 🚀 Tecnologias

- **Angular 22** — Framework SPA
- **GSAP** — Animações
- **TypeScript**
- **CSS3** com custom properties

## 📁 Estrutura

```
site-xavier/
├── src/
│   ├── index.html           # Entry point HTML
│   ├── main.ts              # Bootstrap do Angular
│   ├── styles.css           # Estilos globais
│   └── app/
│       ├── app.ts           # Componente principal
│       ├── app.html         # Template principal
│       ├── app.css          # Estilos do componente
│       └── app.config.ts    # Config do app
├── public/                  # Arquivos públicos
├── angular.json
├── package.json
└── README.md
```

## 🛠️ Como rodar

```bash
npm start
# ou
ng serve
```

Depois abre `http://localhost:4200`.
